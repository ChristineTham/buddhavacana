Besides the compounds of chapter 4, Pāḷi makes new nouns by adding an affix
(`paccaya`) to a word that already exists. Kaccāyana treats two kinds:

* a **secondary derivative** (`taddhitanāma`) is made from another noun by a
  `taddhita` affix {344}–{405}: `vāsiṭṭho` ("Vasiṭṭha's descendant") is
  `vasiṭṭha` with the affix `ṇa`;
* a **primary derivative** (`kitanāma`) is made from a root by a `kita` or an
  `uṇādi` affix. The `kita` affixes, which make the participles, absolutives,
  infinitives and agent nouns that chapter 2 marks 🔽, are tabled in
  Appendix J; the `uṇādi` affixes {624}–{673}, which make individual nouns such
  as `samatho` ("calm") and `gehaṁ` ("house"), are the second half of this
  chapter.

A `taddhita` affix is added to the noun as it stands in the sense the rule
names, the `vibhatti` ending of the base and the meaning-word are elided
{317}, and the new word takes a `vibhatti` ending of its own:

| | vasiṭṭhassa + apaccaṁ (vasiṭṭha + sa ⑥⨀, apacca + si ①⨀) | rule |
| --- | --- | :-: |
| → | vasiṭṭhassa + ṇa + ~~apaccaṁ~~ | {344} |
| → | vasiṭṭha + ~~ssa~~ + ṇa | {317} |
| → | vasiṭṭha + ~~ṇ~~a | {396} |
| → | v~~a~~(ā)siṭṭha + a | {400} |
| → | vāsiṭṭh~~a~~ + a | {83} |
| → | vāsiṭṭha + si (①⨀) | |
| → | vāsiṭṭha + ~~si~~(o) | {104} |
| → | **vāsiṭṭho** | |

Many affixes are written with a `ṇ` that is not part of the affix: it marks
the affixes after which the first vowel of the base is strengthened, `a` to
`ā`, `i` to `e`, `u` to `o` (`vuddhi`) {400}, {405}, and the `ṇ` itself is
elided {396}. The affix `ṇa` therefore adds only `a`; `ṇika` adds `ika`.

An `uṇādi` affix is added to a root, with the root's own changes:

| | √samu + tha | rule |
| --- | --- | :-: |
| → | sama + tha | {628} |
| → | samatha + si (①⨀) | {601} |
| → | samatha + ~~si~~(o) | {104} |
| → | **samatho** | |

The derived word is marked 🔽 in this book, with the affix as Kaccāyana names
it: 🚹⨀①🔽(ṇa)(vāsiṭṭho), 🚹⨀①🔽(tha)(samatho).

Kaccāyana orders the `taddhita` affixes by the sense they carry, from the
descendant {344} to the ordinals and the adverbs {373}–{399}, and ends with the
changes the affixes bring to the base {400}–{405}. The `uṇādi` rules first say
what the affixes denote, the agent, the action, the purpose, and then list the
affixes that form individual words. The chapter follows that order. Appendix H
tables every `taddhita` rule and Appendix K every `uṇādi` rule.
